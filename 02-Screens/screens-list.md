# App Screens List

1. **Splash + Language Selection**
   - App logo, language options (Hindi, regional languages)

2. **Login/Signup**
   - Phone OTP based — simple rakhna, low-literacy friendly

3. **Home/Dashboard**
   - "Kya karna hai?" — voice/text search bar + popular schemes list

4. **Search/Voice Query Screen**
   - Voice input button, text search, recent searches

5. **Scheme Eligibility Checker Form**
   - Age, income, state, category, occupation input

6. **Scheme Detail Page**
   - Eligibility, documents, process, fees, time-to-complete

7. **Document Checklist Page**
   - Required documents list, kaise banaye guide

8. **Form Filling Wizard**
   - Step-by-step form assistance, RTI draft generator

9. **Nearby Center Map**
   - CSC, tehsil, block office locations, timings, contacts

10. **Application Tracker**
    - Status check, reminders, notifications

11. **Expert Chat/Call Screen**
    - Connect with verified agent, premium feature

12. **Community Q&A Feed**
    - User experiences, sawal-jawab

13. **Profile/Settings**
    - Language change, saved schemes, application history
