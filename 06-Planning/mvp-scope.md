# MVP Scope (Phase 1)

## Kya banana hai sabse pehle:

1. **Language selection + simple onboarding**
2. **15-20 popular schemes/certificates ka database** (text based)
3. **Basic search** (voice optional in v1, text search pehle)
4. **Document checklist per scheme**
5. **Nearby CSC center list** (static data se start)

## Kya SKIP karna hai Phase 1 me:
- Voice input (complex, baad me add karo)
- Live application status tracking (government API dependency hai)
- Expert help/chat feature (paisa lagane wala feature, pehle validate karo)
- Community Q&A (user base chahiye pehle)
- Multi-state coverage (1 state se start karo)

## Success Metric for MVP
- 100-500 real users app use karein
- Kam se kam 50% users scheme search complete karein
- User feedback collect karo — "kya ye helpful laga?"

## Timeline Estimate (reference ke liye)
- Week 1-2: Design + wireframes
- Week 3-6: Core development (search, database, document guide)
- Week 7: Testing with real users (10-20 log)
- Week 8: Launch soft (ek area/district me)
