# Tech Stack (Reference for later)

## Frontend
- **React Native** — ek hi codebase Android + iOS ke liye
- Alternative: Flutter (agar team ko zyada comfortable ho)

## Backend
- **Firebase** — fast MVP ke liye best (Auth, Firestore, Cloud Functions)
- Alternative: Node.js/Express + PostgreSQL (zyada control chahiye to)

## Database
- Firestore (NoSQL, MVP ke liye easy) ya PostgreSQL (structured data ke liye better)

## Voice/Language (Phase 2 me)
- Google Speech-to-Text API
- Google Translation API

## Maps
- Google Maps API (nearby centers ke liye)

## Notifications
- Firebase Cloud Messaging (FCM)

## Hosting/Deployment
- Firebase Hosting/Functions
- Google Play Store + Apple App Store

## Why Firebase for MVP?
- Fast setup, kam backend coding
- Built-in auth (phone OTP easy)
- Real-time database
- Free tier generous hai shuru ke liye
