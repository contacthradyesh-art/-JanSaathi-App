# Validation Plan (Coding se pehle)

## Step 1: Talk to Real Users
- 20-30 log (apne area me) se baat karo
- Poochho: "Kya aapko kabhi government scheme/certificate ke liye problem hui?"
- Unki current process samjho (agent use karte hain? kitna paisa dete hain?)

## Step 2: Fake Door Test
- Simple Google Form ya WhatsApp bot bana kar test karo
- "Scheme check karo" jaisa basic flow simulate karo
- Dekho kitne log actually use karte hain

## Step 3: Landing Page Test
- Ek simple landing page banao app ke baare me
- "Coming Soon — apna number chhodo" waala CTA
- Social media/local groups me share karo, response measure karo

## Step 4: Manual MVP (No-code)
- Google Sheet me schemes database banao
- WhatsApp/Telegram bot se query lo aur manually reply karo
- Dekho log kya-kya poochte hain, kaunsi schemes zyada demand me hain

## Decision Point
Agar 30+ log genuinely interested dikhein aur real problem confirm ho,
tabhi full app development shuru karo.

## Key Questions to Validate
1. Kya log paisa dene ko ready hain expert help ke liye?
2. Kya existing solutions (agents/cyber cafe) itne bure hain ki log switch karenge?
3. Kaunsa area/state se start karna best hoga?
