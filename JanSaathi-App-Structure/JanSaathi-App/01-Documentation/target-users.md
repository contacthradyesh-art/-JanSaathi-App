# Target Users

## Primary Users
1. **Rural aur semi-urban citizens** (tier 3/4 cities, villages)
2. **Low literacy / first-time smartphone users**
3. **Migrant workers** — jinhe apne home state ki schemes ka pata nahi
4. **Senior citizens** — jo forms bharne me help chahte hain

## User Personas

### Persona 1: Ramesh (45, Farmer, Tier-4 town)
- Smartphone use karta hai but complex apps se pareshan ho jata hai
- Hindi me hi comfortable hai
- Kisan schemes ke baare me nahi pata

### Persona 2: Sunita (60, Homemaker, Village)
- Widow pension ke liye apply karna chahti hai
- Reading likhna limited hai, voice input better suit karega
- Bête/relatives ki madad leti hai normally

### Persona 3: Amit (28, Migrant Worker, City)
- Doosre state se aaya hai kaam ke liye
- Apne home state ki schemes track karna chahta hai
- Digital literacy thodi better hai

## Secondary Users
- **Verified Agents/CSC Partners** — jo premium help provide karte hain
- **NGOs** — jo content verify karte hain aur partnership karte hain
