# Sample Schemes Database (MVP Reference — 15-20 schemes)

## Format for each scheme entry:
```
Name:
Level: (Central/State)
Eligibility:
Benefits:
Required Documents:
Application Process:
Fees:
Time to Process:
```

## Sample Entries

### 1. Pradhan Mantri Awas Yojana (PMAY)
- Level: Central
- Eligibility: EWS/LIG/MIG income groups, no pucca house
- Benefits: Housing subsidy
- Documents: Aadhaar, Income certificate, Bank passbook
- Process: Online application via PMAY portal or CSC

### 2. Ayushman Bharat (PM-JAY)
- Level: Central
- Eligibility: SECC 2011 database based
- Benefits: Health insurance up to 5 lakh
- Documents: Aadhaar, Ration card
- Process: CSC center or hospital empanelment desk

### 3. Ration Card (New/Modification)
- Level: State
- Eligibility: State resident
- Benefits: Subsidized food grains
- Documents: Aadhaar, Address proof, Income certificate
- Process: State food dept portal or tehsil office

### 4. Income Certificate
- Level: State
- Eligibility: State resident
- Documents: Aadhaar, Address proof, Self-declaration
- Process: Tehsil/SDM office or online state portal

### 5. Caste Certificate
- Level: State
- Eligibility: Belonging to SC/ST/OBC category
- Documents: Aadhaar, Family caste proof
- Process: Tehsil office
