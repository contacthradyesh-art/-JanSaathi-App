# Module C: Document Guide

## Purpose
Har certificate/scheme ke liye required documents ki list dikhana.

## Features
- Document checklist per scheme
- Documents kaise banaye (agar missing hai) uska guide
- Sample filled forms dikhana (reference ke liye)
- Document validity check (expiry dates)

## User Flow
1. User scheme select kare
2. App document list dikhaye (checkboxes ke saath)
3. Missing document par tap karne se "kaise banaye" guide khule
