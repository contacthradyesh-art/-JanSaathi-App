# Module F: Application Status Tracker

## Purpose
User apna application number dale aur status check kare.

## Features
- Application number input
- Status check (jahan tak government API allow kare)
- Reminders — "aapka document 3 din me ready hoga"
- Notification history

## User Flow
1. User application number enter kare
2. App status fetch kare (API/manual update)
3. Push notification bheje jab status change ho
