# Module D: Application Assistant

## Purpose
Step-by-step form filling me madad karna.

## Features
- Step-by-step form filling wizard
- RTI application draft generator
- Application submit karne ke baad tracking number save karna
- Auto-save progress (agar beech me chhodna pade)

## User Flow
1. User "Apply karo" button dabaye
2. Wizard step-by-step fields poochhe (simple language me)
3. Final form preview dikhaye
4. Submit ke baad tracking number save ho
