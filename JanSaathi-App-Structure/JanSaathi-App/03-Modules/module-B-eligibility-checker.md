# Module B: Scheme Eligibility Checker

## Purpose
User apni details dale aur app matching government schemes dikhaye.

## Input Fields
- Age
- Income (monthly/annual)
- State
- Category (General/OBC/SC/ST)
- Occupation
- Gender

## Output
- Matching central + state level schemes list
- Har scheme ka simple explanation — kya milega, kaise apply kare
- Eligibility percentage/match score (optional)

## User Flow
1. User form fill kare (ya voice se bataye)
2. App calculate kare kaunsi schemes eligible hain
3. List dikhaye, priority ke hisaab se sorted (zyada benefit wali upar)
