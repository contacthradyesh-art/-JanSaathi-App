# Module A: Voice-First Query System

## Purpose
User apni bhasha me bol kar ya type karke apni problem bataye.

## Features
- Multiple regional languages support (Hindi, Bhojpuri, Marathi, Tamil, etc.)
- Voice-to-text conversion
- Natural language query understanding — e.g. "Mujhe ration card banwana hai"
- App simple steps me guide kare

## User Flow
1. User microphone icon tap kare
2. Bole apni problem (ya type kare)
3. App query ko relevant scheme/certificate se match kare
4. Result dikhaye — simple steps ke saath

## Tech Notes (baad ke liye)
- Google Speech-to-Text API
- Google Translation API for regional languages
- Basic NLP/keyword matching for MVP (advanced AI baad me)
