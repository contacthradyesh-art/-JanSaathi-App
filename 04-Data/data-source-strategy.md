# Data Source Strategy

## Phase 1 (MVP)
- Manually curate 15-20 popular schemes/certificates
- Static database (JSON/Firestore) — no live API dependency
- Focus on 1-2 states initially (jahan se validation start karoge)

## Phase 2 (Scale)
- Government open data portals se integrate (data.gov.in)
- State-specific portals se automated scraping/API (jahan available ho)
- NGO partnerships se content verify aur update karwana

## Phase 3 (Mature)
- Official government API partnership
- Real-time status tracking integration
- Multi-state, multi-language full coverage

## Data Maintenance
- Monthly/quarterly review cycle
- Community feedback loop (users flag outdated info)
- Dedicated content team ya NGO volunteer network
